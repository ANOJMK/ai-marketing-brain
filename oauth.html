OAuth 2.0 Authentication

AI Marketing Brain connects user accounts using the official OAuth 2.0 authorization framework provided by supported social media platforms.

We never request, collect or store user passwords. Users authenticate directly with the platform they choose to connect.

OAuth 2.0 Authorization Flow

AI Marketing Brain uses the official OAuth 2.0 authorization framework provided by supported social media platforms. Authentication is completed directly on the provider's website.

1

User Starts Connection

The user selects a supported platform and clicks "Connect Account".

2

Redirect to Provider

The user is redirected to the official authentication page of the selected platform.

3

User Authentication

Login credentials are entered only on the official platform. Brain Africa Labs never has access to the user's password.

4

User Consent

The platform displays the requested permissions. Users can approve or deny access.

5

Authorization Granted

After approval, the platform returns an authorization code that is exchanged securely for access tokens.

6

Secure Connection

The connected account is now available for the features authorized by the user.

Requested Permissions

Basic Profile

Access to basic public profile information required to identify the connected account.

Content Publishing

Permission to publish content only after explicit user authorization.

Media Upload

Upload images or videos before publication through official APIs.

Analytics

Retrieve campaign statistics when supported by the connected platform.

Secure Token Management

Access Tokens

OAuth access tokens are securely managed and used only for authorized API requests.

Refresh Tokens

When supported by the platform, refresh tokens are used to renew sessions without requiring repeated logins.

Encryption

Tokens are transmitted over encrypted HTTPS connections.

Revocation

Users may disconnect their accounts and revoke authorization at any time through the platform.

Benefits of OAuth 2.0

No Password Sharing

Users authenticate directly with the social media platform. Brain Africa Labs never requests or stores passwords.

Granular Permissions

Users approve only the permissions required for AI Marketing Brain to perform authorized actions.

Easy Revocation

Connected accounts can be disconnected at any time from the provider's security settings.

Industry Standard

OAuth 2.0 is the standard authentication framework used by major online platforms worldwide.

Privacy Protection

Your Privacy Comes First

AI Marketing Brain follows a privacy-first approach. We only access information necessary to provide the features authorized by the user.

  • Official OAuth authentication only.
  • No collection of social media passwords.
  • User authorization required before every connection.
  • HTTPS encrypted communication.
  • Users may revoke access at any time.

Security Best Practices

1

Official Login

Always authenticate through the official login page of the selected platform.

2

Review Permissions

3

Disconnect Unused Apps

Remove applications you no longer use from your connected accounts.

4

Keep Your Account Secure

Enable multi-factor authentication (MFA) whenever supported by your platform.
