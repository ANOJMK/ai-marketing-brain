AI Marketing Brain

AI-powered marketing automation

AI Marketing Brain is the flagship product of Brain Africa Labs. It helps businesses, agencies and creators create, review, schedule and publish marketing content through official social media APIs.

Social media accounts are connected using the authorization mechanisms provided by each platform. Users remain in control of the permissions granted to AI Marketing Brain.

TikTok Integration

TikTok Content Posting API

Brain Africa Labs integrates with TikTok through TikTok's official Content Posting API.

Users connect their TikTok account through the official TikTok authorization flow and explicitly authorize the permissions requested by AI Marketing Brain.

After authorization, AI Marketing Brain uses the authorized access token to perform permitted API operations, including video publishing through the TikTok Direct Post workflow where supported.

Brain Africa Labs does not request or store TikTok account passwords.

Official TikTok API

TikTok account operations are performed through TikTok's official API endpoints.

OAuth Authorization

Users authorize access directly through the TikTok authorization experience.

Authorized Publishing

Authorized users can submit video content for publication through the supported TikTok publishing workflow.

Publication Status

AI Marketing Brain can monitor the publication process using the API response and publication status.

TikTok Publishing Flow

The following workflow describes how an authorized user can publish video content through the official TikTok API.

1

User Connects TikTok

The user chooses TikTok in AI Marketing Brain and starts the account connection process.

2

TikTok Authorization

The user is redirected to the official TikTok authorization experience.

3

User Consent

TikTok displays the permissions requested by the application. The user can approve or deny access.

4

Authorization Code

After authorization, the application receives the authorization response and securely exchanges the authorization code for an access token.

5

Creator Information

The application retrieves the available creator information and publishing options required by the TikTok publishing workflow.

6

Video Upload / Direct Post

The authorized workflow submits the video using the supported TikTok Content Posting API operation.

7

Publication Status

The application checks the returned publication status to determine whether processing has completed or requires further processing.

TikTok Permissions

Account Information

Access to account information required to identify the authorized TikTok account and support the publishing workflow.

Video Publishing

The publishing permission allows AI Marketing Brain to submit authorized video content to the connected TikTok account through the official TikTok Content Posting API.

User Consent

Publishing actions require the user to authorize the requested permissions through TikTok.

Limited Access

AI Marketing Brain uses API access only for the authorized functionality and permissions granted by the user.

TikTok Publication Visibility

TikTok Production and Audit Requirements

TikTok controls the publication capabilities and visibility available to applications using its Content Posting API.

During development and before the application has completed the applicable TikTok production review, TikTok may restrict the visibility of content published through the API.

Brain Africa Labs does not attempt to bypass these platform restrictions.

Once the application is approved for the applicable production capabilities, AI Marketing Brain will use the publication options made available by TikTok and the connected user's account.

OAuth 2.0 Authorization Flow

Authentication is completed directly on the official platform. Brain Africa Labs never receives the user's social media password.

1

User Starts Connection

The user selects a supported platform and clicks "Connect Account".

2

Redirect to Provider

The user is redirected to the official authentication page of the selected platform.

3

User Authentication

Login credentials are entered only on the official platform.

4

User Consent

The platform displays the requested permissions and the user can approve or deny access.

5

Authorization Granted

The platform returns an authorization response that is processed securely by the application.

6

Secure API Access

The authorized access token is used for permitted API requests.

Secure Token Management

Access Tokens

OAuth access tokens are used for authorized API requests and are not used as substitutes for user passwords.

Refresh Tokens

Where supported by the platform, refresh tokens may be used to renew authorization without requiring the user to authenticate again.

HTTPS

OAuth credentials and API communications are transmitted through encrypted HTTPS connections.

Revocation

Users can revoke authorization through the relevant platform account controls.

What Brain Africa Labs Does Not Do

  • We do not request social media passwords.
  • We do not ask users to provide their platform login credentials directly to Brain Africa Labs.
  • We do not bypass platform authentication.
  • We do not bypass platform API restrictions or publication controls.
  • We do not publish content without the required authorization.
  • We use official APIs and authorization mechanisms provided by the supported platforms.

Privacy Protection

Privacy-First Approach

AI Marketing Brain follows a privacy-first approach. The platform is designed to access only the information necessary to provide features authorized by the user.

  • Official OAuth authentication.
  • No collection of social media passwords.
  • User authorization before protected API access.
  • Encrypted HTTPS communication.
  • Ability to disconnect authorized accounts.
  • Privacy and data deletion information available through the website.
