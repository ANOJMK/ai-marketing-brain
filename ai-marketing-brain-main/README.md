# Brain Africa Labs — AI Marketing Brain

Brain Africa Labs is an AI marketing automation product site and application demo.

## TikTok audit flow
A reviewer-friendly flow is available at:
`/app/dashboard.html`

Flow: Create Campaign → Select Video → Select TikTok → Connect TikTok → Account Connected → Caption + Privacy → Review → Publish → Success.

The frontend never stores TikTok client secrets. Backend OAuth/token handling is delegated to the configured n8n integration.
